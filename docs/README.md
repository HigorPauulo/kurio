# Documentação

Comece por **[STATUS](STATUS.md)**: onde o projeto está e o que fazer agora, em uma página. O próximo
passo de código sai da fila do [ROADMAP](ROADMAP.md). O resto é referência.

> **Cada fato de estado tem um dono, e só um.** Onde estou e o que trava: [STATUS](STATUS.md). Ordem e
> progresso: [ROADMAP](ROADMAP.md). Nenhum outro documento declara "hoje o projeto tem".
